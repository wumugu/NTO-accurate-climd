# НТО- Аккуратный подъём

Решение задачи **«Аккуратный подъём»** из НТО 2026/27, этап 1, направление **«Технологии беспроводной связи»**.

## Описание

Марсоход должен добраться до единственной наиболее высокой точки рельефа.

Проверяющая система передаёт текущее состояние в виде пяти целых чисел:

1. текущая высота;
2. высота впереди;
3. высота сзади;
4. высота слева;
5. высота справа.

За один шаг марсоход может переместиться только при перепаде высот не более `1`.

Доступные команды:

- `FW` — шаг вперёд;
- `BW` — шаг назад;
- `RL` — поворот налево на 90°;
- `RR` — поворот направо на 90°;
- `SNP` — завершение подъёма.

Задача интерактивная: после каждой отправленной команды программа должна очистить буфер вывода и считать новое состояние.

## Идея решения

Программа постепенно строит известную часть карты рельефа.

Для каждой клетки сохраняется её высота:

```python
H[(x, y)] = height
```

Посещённые клетки дополнительно сохраняются в множестве `visited`.

Состояние марсохода описывается тремя параметрами:

```text
(x, y, direction)
```

После каждого наблюдения программа:

1. добавляет новые данные о соседних клетках в карту;
2. рассматривает уже известную область как граф состояний;
3. ищет маршрут с учётом поворотов и перемещений;
4. выбирает среди доступных ещё не посещённых клеток наиболее высокую;
5. восстанавливает найденный маршрут;
6. выполняет команды и получает новое состояние.

Для поиска используется `heapq`.

## Проверка возможности движения

Перемещение в соседнюю известную клетку разрешается только при условии:

```python
abs(H[next_cell] - H[current_cell]) <= 1
```

Повороты не меняют координаты, а изменяют только направление:

```text
RL -> поворот налево
RR -> поворот направо
```

## Интерактивный ввод/вывод

После каждой команды используется:

```python
print(cmd, flush=True)
```

что необходимо для немедленной передачи команды проверяющей системе.
